# 项目架构

```
┌─────────────────────────────────────────────────────────────┐
│                    故障分类系统架构                           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  输入层                                                       │
├─────────────────────────────────────────────────────────────┤
│  • quick_start.py - 交互式命令行工具                          │
│  • demo_incident.py - 演示脚本                               │
│  • IncidentClassifier API - 代码集成                         │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  核心分类层 (incident_triage.py)                             │
├─────────────────────────────────────────────────────────────┤
│  IncidentClassifier.classify(description)                   │
│  ├─ 构建 Prompt（系统提示词 + 用户描述）                     │
│  ├─ 调用 LLM（通过 client.py）                              │
│  └─ 多层校验（见下方）                                       │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  LLM 层 (client.py)                                          │
├─────────────────────────────────────────────────────────────┤
│  LLMClient.chat(message, system_prompt)                     │
│  ├─ 读取配置（config.yaml）                                  │
│  ├─ 调用 OpenAI 兼容 API                                     │
│  └─ 返回 JSON 格式响应                                       │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  多层校验架构                                                 │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  第一层：JSON 格式校验                                        │
│  ├─ json.loads() 解析                                        │
│  ├─ 处理 markdown 代码块                                     │
│  └─ 捕获 JSONDecodeError                                     │
│                                                               │
│  第二层：Pydantic Schema 强制校验                             │
│  ├─ 枚举值严格匹配（Literal）                                │
│  ├─ 类型强制检查（str, bool）                                │
│  ├─ 字段长度限制（10-500 字符）                              │
│  ├─ 必填字段验证                                             │
│  └─ 自定义验证器（@field_validator）                         │
│                                                               │
│  第三层：业务逻辑一致性校验                                   │
│  ├─ P0/P1 → needs_human_review=true                         │
│  ├─ P3 → needs_human_review=false                           │
│  ├─ 关键词规则（支付/交易 → P0）                            │
│  └─ 分类优先级（database > deployment）                      │
│                                                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  输出层                                                       │
├─────────────────────────────────────────────────────────────┤
│  IncidentTriage (Pydantic Model)                            │
│  ├─ severity: "P0" | "P1" | "P2" | "P3"                     │
│  ├─ category: availability | latency | database | ...       │
│  ├─ needs_human_review: bool                                │
│  └─ rationale: str (10-500 字符)                            │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  监控与审计                                                   │
├─────────────────────────────────────────────────────────────┤
│  • 详细日志（logging）                                       │
│  • 错误追踪（ValidationError, JSONDecodeError）             │
│  • 业务规则修正记录                                          │
│  • 测试报告（test_results.json）                            │
└─────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════

测试与验证流程：

┌──────────────┐
│ test_cases.py│  20 个生产案例
└──────┬───────┘
       │
       ↓
┌──────────────┐
│run_tests.py  │  自动化测试脚本
└──────┬───────┘
       │
       ├─→ 逐个测试
       ├─→ 对比期望 vs 实际
       ├─→ 计算准确率
       └─→ 生成 test_results.json
               ↓
       ┌──────────────────┐
       │ 准确率统计         │
       ├──────────────────┤
       │ severity: 100%    │
       │ category: 90%     │
       │ needs_human: 100% │
       │ 综合: 90%         │
       └──────────────────┘

┌──────────────────┐
│test_validation.py│  Pydantic 校验测试
└──────┬───────────┘
       │
       ├─→ 测试合法输入
       ├─→ 测试无效枚举
       ├─→ 测试类型错误
       ├─→ 测试缺失字段
       └─→ 测试长度限制
               ↓
       全部拦截成功 ✓
