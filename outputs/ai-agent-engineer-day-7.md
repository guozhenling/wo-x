# AI Agent 工程师：Day 7 — 复盘与巩固

目标：把第 1 周的零散代码变成可解释的能力，而不是匆忙开始下一个框架。

预计：2–3 小时。

## 最低完成线

- [ ] 从头运行 Day 1–6 的核心示例。
- [ ] 写下三个仍不理解的概念。
- [ ] 用自己的话解释一次 tool-calling loop。

## 标准任务

1. 将本周代码按职责整理为：模型调用、Schema、策略、工具、评测、数据。
2. 删除重复或无用代码；不要为了“架构优雅”引入框架。
3. 写一页 `week-1-review.md`，回答：

   - Agent 与普通聊天机器人有什么区别？
   - 为什么模型输出需要 Schema 校验？
   - 为什么高风险判断要有确定性规则？
   - 一次工具调用如何从模型到 Python 再返回模型？
   - 你的评测发现了什么失败模式？

4. 录一段 2–3 分钟讲解，或对着自己讲清楚以上五点。
5. 选择两个失败案例，尝试在不增加新框架的前提下修复。

## 进入第 2 周的门槛

你应能独立画出：

```text
输入 → 模型 → 受控工具 → 证据 → 最终回答 → 评测
```

画不出来或解释不清楚时，优先复做 Day 4 或 Day 6，而不是进入 MCP。

## 完成证明

- 一个整理后的目录。
- 一份 Week 1 复盘。
- 全部本周测试通过，或有明确记录的失败原因。
