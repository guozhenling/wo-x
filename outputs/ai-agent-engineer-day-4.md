# AI Agent 工程师：Day 4 — 最小 Tool-Calling Loop

目标：看懂并实现 Agent 最核心的循环：模型请求工具，程序执行工具，再把结果交回模型。

预计：3 小时。

## 今天不追求什么

不做多 Agent、记忆或复杂编排。今天只允许一个工具 `search_logs`，最多两轮调用。

## 最低完成线

- [ ] 将 `search_logs` 的名称、说明与 JSON Schema 传给模型。
- [ ] 处理一次模型发起的工具调用。
- [ ] 将工具结果回传给模型并获得最终文字回答。

## 标准任务

1. 为 `search_logs` 写清楚工具描述：什么时候该用、能返回什么、不能做什么。
2. 调用 OpenAI 兼容接口时携带工具定义。
3. 收到工具调用后，先用 Pydantic 验证参数，再执行 Python 函数。
4. 把工具结果作为工具消息交回模型。
5. 限制最多 2 次工具调用；超过时返回“证据不足”。
6. 保存一份调用轨迹：用户输入、模型工具请求、工具结果、最终答案。

## 今天要理解的循环

```text
用户问题 → 模型决定要查什么 → Python 校验并查日志 → 模型基于证据作答
```

模型不能直接运行 Python，也不能绕过参数校验。

## 完成证明

- 一个会主动查日志的问题，例如“支付服务为什么报错？”
- 一份包含工具调用与最终答案的 trace。
- 一项测试：模型请求非法 `limit` 时，工具不执行。

## 明天的入口

Day 5 加入第二种证据：运行手册。你会学习简单检索与引用，不使用向量数据库。
