# AI Agent 工程师：Day 5 — 最小知识检索与引用

目标：让回答有来源。模型可以总结运行手册，但不能假装自己知道未提供的内部知识。

预计：2.5–3 小时。

## 最低完成线

- [ ] 写 3 份 Markdown 运行手册。
- [ ] 实现 `search_runbook(keyword)`。
- [ ] 最终回答中显示文档 ID。

## 标准任务

1. 创建三份运行手册：支付 5xx、数据库死锁、发布回滚。
2. 每份文档包含标题、文档 ID、适用条件、检查步骤和人工升级条件。
3. 用关键词匹配实现检索；今天不需要向量数据库。
4. 返回结果时保留 `document_id` 和匹配片段。
5. 让 Day 4 的循环可以选择查日志或查运行手册。
6. 写 5 个测试：正确命中、无结果、引用保留、无关查询、输出长度限制。

## 核心原则

```text
模型的回答 ≠ 证据
日志、指标、运行手册的明确引用 = 可检查的证据
```

## 完成证明

- 三份 Markdown 文档。
- 一个只读检索工具与 5 个测试。
- 一次最终回答，其中至少引用一个文档 ID。

## 明天的入口

Day 6 不再增加功能，而是为现有能力建立评测集，找出失败模式。
