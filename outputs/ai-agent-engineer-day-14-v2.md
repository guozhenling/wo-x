### 选做作业（2 小时）

**任务 1: Web 界面**
```python
# app.py
from flask import Flask, request, jsonify
from incident_classifier_v1 import IncidentClassifierV1

app = Flask(__name__)
classifier = IncidentClassifierV1()

@app.route('/api/classify', methods=['POST'])
def classify():
    data = request.json
    result = classifier.classify(data['description'])
    return jsonify(result)

if __name__ == '__main__':
    app.run(debug=True)
```

**任务 2: Docker 部署**
```dockerfile
FROM python:3.9-slim

WORKDIR /app
COPY . .
RUN pip install -r requirements.txt

CMD ["python", "app.py"]
```
